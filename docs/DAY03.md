# DAY03：按键、PWM、外部中断与串口

## 完成内容

1. KEY1轮询控制红灯翻转；
2. KEY1/KEY2分别启停红、绿PWM呼吸灯；
3. KEY1外部中断触发一次非阻塞蜂鸣；
4. KEY1计数、KEY2清零，并通过USART1输出事件。

## 关键认识

- 轮询适合入门和低速输入；EXTI能及时响应，但中断回调应尽量短。
- `volatile`让主循环能观察中断修改的事件变量，但不自动保证复杂操作的原子性。
- 呼吸效果由PWM占空比变化产生；使用`HAL_GetTick()`可让两路灯独立运行。
- 串口配置为115200、8数据位、无校验、1停止位；短日志暂用阻塞发送。
- RGB灯低电平有效，PG7蜂鸣器高电平有效，初始化电平决定复位瞬间是否误动作。

## 实物结果

- 按键可以稳定切换灯状态与呼吸状态；
- 外部中断事件能触发蜂鸣；
- 电脑串口可连续显示KEY1递增和KEY2清零结果。
