# Day 02：七色 RGB 流水灯与蜂鸣提示

日期：2026-08-15

状态：已完成并通过实物验证

## 项目目标

在 M1 的三个基础颜色之上，通过 RGB 三路开关组合得到七种发光颜色。七种颜色播放完成后关闭 RGB，并让板载蜂鸣器短响一次。

## 硬件映射

| 功能 | MCU 引脚 | 有效电平 | 安全初始电平 |
|---|---|---|---|
| 红色通道 | PF6 | Low | High（熄灭） |
| 绿色通道 | PF7 | Low | High（熄灭） |
| 蓝色通道 | PF8 | Low | High（熄灭） |
| 蜂鸣器 | PG7 | High | Low（静音） |

四个引脚均配置为推挽输出、无上下拉、低速。GPIOG 时钟必须在访问 PG7 前开启。

## 七色组合

使用 `uint32_t` 的低三位表示 RGB：

```text
bit2 bit1 bit0
 蓝   绿   红
```

| 值 | 通道组合 | 颜色 |
|---:|---|---|
| `001` | 红 | 红 |
| `011` | 红 + 绿 | 黄 |
| `010` | 绿 | 绿 |
| `110` | 绿 + 蓝 | 青 |
| `100` | 蓝 | 蓝 |
| `101` | 红 + 蓝 | 紫 |
| `111` | 红 + 绿 + 蓝 | 白 |

按位或 `|` 用于组合颜色，按位与 `&` 用于检测某个通道是否被选中。它们不同于逻辑或 `||` 和逻辑与 `&&`。

## 程序结构

- 时间参数集中定义为宏，便于调速和修改蜂鸣时长；
- `color_sequence[]` 只负责保存播放顺序；
- `while (1)` 遍历数组并安排灯光、熄灯、蜂鸣和轮次间隔；
- `RGB_SetColor()` 把逻辑颜色掩码转换成三个低有效 GPIO 电平；
- `Buzzer_Beep()` 把 PG7 置高、等待指定时间，再恢复低电平。

源文件 [main.c](../firmware/stm32f407/f407_rgb_7color_buzzer/Core/Src/main.c) 对上述用户代码逐段给出了教学注释。

## 为什么初始状态不同

RGB 是低电平有效，所以三个 LED 引脚初始为 High，避免上电误亮。蜂鸣器是高电平有效，所以 PG7 初始为 Low，避免上电或复位时误响。初始电平应该根据负载的有效极性和系统安全状态选择，不能统一设置成 High 或 Low。

## 当前局限与下一步

`HAL_Delay()` 会阻塞当前执行流。本项目只有顺序灯效和蜂鸣，因此先用它建立可验证基线；加入按键、串口和传感器后，应改成 `HAL_GetTick()` 状态机、定时器或 RTOS 调度。
