# 学习与调试记录

## 2026-08-15 / M1 RGB 流水灯

- 目标：打通 CubeMX → CMake/GCC → OpenOCD → STM32F407 实物运行的完整链路。
- 硬件与接线：野火霸天虎 V2、STM32F407ZGT6、fireDAP；SWD 接口连接，开发板单独供电。
- 配置：HSE 25 MHz，SYSCLK 168 MHz；PF6/PF7/PF8 为推挽输出、无上下拉、低速、初始高电平。
- 代码：低电平点亮三个板载 LED，分别延时后熄灭，循环执行。
- 构建：成功，Flash 5972 B，RAM 1584 B。
- 下载：CMSIS-DAP 和 Cortex-M4 识别成功；写入、校验和复位成功。
- 实测：红、绿、蓝按顺序交替；调整 `LED_STEP_DELAY_MS` 可改变速度。
- 故障修正：确认 PLLQ 灰色是未被外设使用；确认板载灯无需面包板；把代码保持在 CubeMX 用户区。
- 尚未覆盖：按钮输入、按键抖动、外部中断、非阻塞时序。
- 下一步：M2 七色 RGB 组合与蜂鸣提示。

## 2026-08-15 / M2 七色 RGB 与蜂鸣提示

- 目标：利用三个 RGB 通道的组合产生七种颜色，并在每轮结束时给出声音提示。
- 硬件：PF6/PF7/PF8 控制低电平有效的 RGB 三通道；PG7 高电平使能蜂鸣器。
- 配置：保留 168 MHz 时钟树；LED 为推挽输出、初始高电平；蜂鸣器为推挽输出、初始低电平。
- 代码：用三个位表示 RGB，使用按位或组合颜色，使用数组定义播放顺序，并用两个静态函数封装硬件操作。
- 构建：教学注释版成功，Flash 6196 B，RAM 1584 B。
- 实测：七种颜色依次变化；一轮结束后灯熄灭，蜂鸣器短响一次，然后进入下一轮。
- 故障修正：删除重复的 CubeMX 用户区标记和重复循环；把魔法数字改为集中定义的时间宏。
- 当前局限：仍使用 `HAL_Delay()` 阻塞执行，播放期间不能及时处理其他轮询任务。
- 下一步：M3 按键输入与基于 `HAL_GetTick()` 的非阻塞消抖。

## 2026-08-29 / M3-M6 按键、PWM、EXTI与USART1

- 完成KEY1轮询翻转红灯，理解输入有效电平、状态变量和消抖。
- 使用TIM10_CH1/PF6和TIM11_CH1/PF7实现两路独立呼吸灯，使用`HAL_GetTick()`避免长时间阻塞。
- 将PA0配置为外部中断，回调只记录事件，蜂鸣器动作放在主循环执行。
- 使用KEY1计数、KEY2清零，并通过USART1向macOS串口终端输出结果。
- 修正按键宏名、ELF任务名、串口端口选择和蜂鸣器有效电平问题。

## 2026-08-30 / M7-M8 内部定时与外部计数

- TIM6以84MHz定时器时钟、PSC=8399、ARR=19999形成2秒更新周期。
- 每次TIM6事件计数加一、翻转低电平有效红灯，并输出累计时间。
- PA0配置为TIM2_ETR外部时钟模式2，PSC=0、ARR=9，实现0至9硬件计数。
- 第10个边沿使CNT自动回零并触发更新中断，NUM加一，TOTAL=`NUM*10+CNT`。
- 修正USART1漏配、TIM2 NVIC漏选以及主循环检测代码漏贴问题。
- 下一步使用TIM3输出PWM、TIM4 PWM Input测量频率和占空比。
