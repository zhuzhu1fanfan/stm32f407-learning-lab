# 学习与调试记录

## 2026-08-15 / M1 RGB 流水灯

- 目标：打通 CubeMX → CMake/GCC → OpenOCD → STM32F407 实物运行的完整链路。
- 硬件与接线：野火霸天虎 V2、STM32F407ZGT6、fireDAP；SWD 接口连接，开发板单独供电。
- 配置：HSE 25 MHz，SYSCLK 168 MHz；PF6/PF7/PF8 为推挽输出、无上下拉、低速、初始高电平。
- 代码：低电平点亮三个板载 LED，分别延时后熄灭，循环执行。
- 构建：成功，Flash 5972 B，RAM 1584 B。
- 下载：CMSIS-DAP 和 Cortex-M4 识别成功；写入、校验和复位成功。
- 实测：红、绿、蓝按顺序交替；调整 `LED_STEP_DELAY_MS` 可改变速度。
- 故障修正：确认 PLLQ 灰色是未被外设使用；确认板载灯无需面包板；把代码保持在 CubeMX 用户区。
- 尚未覆盖：按钮输入、按键抖动、外部中断、非阻塞时序。
- 下一步：M2 按键输入与软件消抖。
