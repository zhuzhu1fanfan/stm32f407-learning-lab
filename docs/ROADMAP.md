# 学习路线与验收标准

主线使用 STM32CubeMX + VS Code + CMake/GCC + HAL。每个外设都回答：硬件接在哪里、时钟从哪里来、软件如何控制、怎样证明结果。

## 第一阶段：板级 Bring-up

- [x] M1 RGB 流水灯：GPIO 输出、RCC、推挽输出、有效电平、阻塞延时。
- [x] M2 七色 RGB + 蜂鸣提示：位掩码、颜色组合、数组遍历、函数封装、PG7 安全默认状态。
- [x] M3 按键输入：轮询、有效电平、软件消抖和状态翻转。
- [x] M4 双路PWM呼吸灯：TIM10/TIM11、频率和占空比、非阻塞渐变。
- [x] M5 外部中断蜂鸣：EXTI、NVIC、事件标志和非阻塞输出。
- [x] M6 串口事件计数：USART1、115200 8-N-1、KEY1计数和KEY2清零。

阶段验收：按键切换灯效和蜂鸣器状态，串口输出事件；复位后无随机蜂鸣，并有构建与实物证据。

## 第二阶段：传感器与可靠时序

- [ ] 确认温度传感器实物型号，再选择 DHT11、DS18B20 或板载传感器驱动。
- [ ] 使用定时器或 DWT 实现微秒时序，对比阻塞延时。
- [ ] 增加超时、校验、错误码和断线恢复。
- [ ] 连续采样并输出成功率、错误次数和采样周期。

阶段验收：连续运行至少 30 分钟；断开传感器能报告错误，恢复连接后能继续采样。

## 第三阶段：定时器、PWM、中断与 DMA

- [x] TIM6内部定时中断驱动计数、LED翻转和串口日志。
- [x] TIM2 ETR外部脉冲计数、自动重装与十进制进位。
- [x] PWM呼吸灯，使用定时器硬件输出和非阻塞占空比更新。
- [x] PWM输入捕获：用CCR1测周期、CCR2测高电平并输出频率与占空比。
- [x] ADC扫描 + DMA循环采集电位器、内部温度和VREFINT，并通过串口显示。
- [ ] UART DMA 环形接收，处理粘包、溢出和错误恢复。

阶段验收：保留测量或逻辑分析证据，并能解释实时性和 CPU 占用差异。

## 第四阶段：FreeRTOS 环境监测与告警终端

组合周期采样、按键/命令、日志、超阈值告警、队列、互斥、软件定时器、看门狗与故障恢复。

- [x] 优先级反转对照：二值信号量与带优先级继承的互斥锁。
- [ ] 三任务电位器状态监控器：周期采样、队列传递、RGB/蜂鸣告警和串口监控。
- [ ] 任务挂起/恢复与软件定时器。
- [ ] 栈水位、运行时统计、看门狗与故障注入。

阶段验收：给出任务表、优先级依据、栈水位、运行时统计和故障注入结果。
